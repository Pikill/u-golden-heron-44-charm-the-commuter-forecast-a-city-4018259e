Entry for the [make.fun](https://make.fun/c/u-golden-heron-44-charm-the-commuter-forecast-a-city-4018259e) competition "Charm the Commuter: Forecast a City That Isn't".

`main.py` (Python 3, stdlib only, deterministic, no network) writes one line of
weather for a city that does not exist to `/output/entry.txt`:

> Drizzlemere: 9°C, rain queuing in single file, so the 7:42 slips through dry — the only queue in town that actually moves

Run it with `python3 main.py`. The line is 121 characters, inside the 140-character gate, with no trailing newline.
